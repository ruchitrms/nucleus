# Nucleus

Production-oriented FastAPI backend scaffold for learning backend engineering in phases.

## Planned Stack
- FastAPI
- PostgreSQL
- Redis
- Background jobs (Celery or RQ)
- Docker
- Pytest

## Project Layout
- src/nucleus_api: application package
- tests/unit: fast isolated tests
- tests/integration: service and data-flow tests
- scripts: local developer scripts
- docs: project documentation and planning notes

## Next Step
Define baseline tooling (dependency management, linting, formatting, test runner) before writing business logic.
